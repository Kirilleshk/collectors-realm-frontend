# /handoff — учёт сессий

Аргумент: `$ARGUMENTS`. Пусто → **Запись**. `где мы` → **Где мы**.

Файлы: `HANDOFF.md` (открытые хвосты + сессии за 3 дня, новые сверху),
`docs/handoff-archive/ГГГГ-ММ.md` (архив по месяцам). Репозитории: фронт
`E:\MyProgect\collectors-realm`, бэкенд `E:\MyProgect\collectors-realm-backend`.
Всё — по-русски.

## Запись (`/handoff`)

1. **Время.** Начало сессии — из строки `[handoff] Сессия <id> начата <время>`
   в контексте (её печатает хук SessionStart). Нет строки → `ls -t .claude/sessions | head -1`
   и прочитать этот файл (имя = id сессии). Нет и его → начало `?`, сказать об этом
   пользователю. Конец — `date '+%Y-%m-%d %H:%M'`. Время НИКОГДА не выдумывать.
2. **Факты.** В обоих репозиториях: `git log --since="<начало>" --format="%h %s"`
   и `git status --short` (незакоммиченное — упомянуть в хвостах).
   Прод: бэкенд — push в main = автодеплой; фронт — задеплоен, только если в этой
   сессии реально выполнялся `npm run deploy`. Иначе при изменениях в `src/`/`App.js`
   писать `⚠️ запушено, НЕ задеплоено` и добавить это в хвосты.
3. **Одна сессия — одна запись.** Если в `HANDOFF.md` уже есть запись с
   `<!-- session: <первые 8 символов id> -->` — дополнить её (время конца,
   пункты, коммиты), не создавать новую. Иначе — вставить новую сразу под `## Сессии`:

   ```markdown
   ### ГГГГ-ММ-ДД ЧЧ:ММ–ЧЧ:ММ — <суть сессии одной строкой>
   <!-- session: <id8> -->
   - **Сделано:** …
   - **Файлы:** …
   - **Коммиты:** фронт <hash> · бэкенд <hash или —>
   - **Прод:** не требуется / задеплоено (<версия>) / ⚠️ запушено, НЕ задеплоено
   - **Хвосты:** … / —
   ```
   Сессия через полночь: `### 2026-09-30 23:10 – 2026-10-01 01:05 — …` (дата — день начала).
   Порядок в файле и ротация в архив — по времени КОНЦА сессии: продолженная
   многодневная сессия сама встаёт наверх и не уезжает в архив по дате начала.
   При продолжении сессии обновлять время конца в её заголовке.
   Внутри записи не использовать заголовки `#`/`##`/`###` — по ним режутся записи.
4. **Открытые хвосты** (`## Открытые хвосты`): добавить новое (что ждёт Марка/Кирилла,
   TODO с датой, не проверено, не задеплоено), убрать то, что в этой сессии реально
   закрыто и проверено. Формат: `- **<Ждёт Марка|Ждёт Кирилла|TODO после ДД.ММ|Не сделано|…>:** суть (дата появления).`
5. **Ротация:** `node .claude/skills/handoff/rotate.js` — записи старше 3 дней уедут в архив.
6. **Коммит и push** (только документация, прод не трогает):
   `git add HANDOFF.md docs/handoff-archive && git commit -m "docs: handoff ГГГГ-ММ-ДД"` + `git push`.
   Другие незакоммиченные файлы в этот коммит не брать.
7. Пользователю — 2–3 строки: что записано, сколько хвостов, что уехало в архив.

## Где мы (`/handoff где мы`)

1. Прочитать `HANDOFF.md` целиком (он короткий).
2. В обоих репозиториях: `git status --short` и `git log -3 --format="%h %ci %s"`.
3. Ответить кратко, по блокам:
   - **Последняя сессия:** когда и что сделано (1–3 строки).
   - **Горит:** TODO с наступившей датой, `⚠️ НЕ задеплоено`, незакоммиченные изменения.
   - **Ждёт Марка / ждёт Кирилла:** из открытых хвостов.
   - **Предлагаю начать с:** один конкретный следующий шаг.
   Архив не читать, если пользователь сам не просит.
