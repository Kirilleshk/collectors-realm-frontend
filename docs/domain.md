# Предметная область

## Роли пользователей

```
COLLECTOR     → Коллекционер      🗿  синий
MASTER_REPAIR → Мастер по ремонту 🔧  accent/оранжевый
CUSTOMIZER    → Кастомизатор      🎨  фиолетовый
DIORAMA       → Мастер диорам     🏔  зелёный
ADMIN         → полная админка (Кирилл)
ANALYTICS     → только статистика (для клиента-заказчика)
MODERATOR     → ограниченная админка для Марка: «Товары», «Люди» (блокировка),
                «Чат» (поддержка + удаление сообщений), «Игра», «Статистика».
                Без доступа только к «Релизы» (`isAdmin`-only таб в AdminScreen.js,
                остальные — `isStaff`)
```

Доступ к вкладке «Админ»: `user?.roles?.includes('ADMIN'|'ANALYTICS'|'MODERATOR')`
в `App.js` — по роли из JWT, не по email. Бэкенд отдельно проверяет ту же роль для
стафф-эндпоинтов (`/api/cards/admin/*` и т.п.).

## Кто продаёт (с 20.10.2026)

Кнопка «Продать» в центре нижнего меню (`SellProductScreen.js`) — выставить товар может любой
пользователь. Товар персонала (ADMIN/MODERATOR) — товар магазина Markeltoys
(`sellerId = null`, связь — только «Написать магазину», чат с администрацией;
WhatsApp/Max с ненастоящим номером убраны 20.10; можно аукцион).
Товар пользователя — `sellerId` = автор, покупатель связывается с продавцом
напрямую по `sellerTelegram`/`sellerPhone` (публичные). Править/снимать/удалять
— владелец или персонал: в карточке панель управления (сразу под ценой), кнопок
покупателя у них нет; список своих — «Моё → Объявления» (у персонала там товары
магазина).

## Чат с продавцом

`ChatScreen.js` («Связаться с продавцом») переиспользует `SupportMessage` с привязкой
к товару (`productId`/`productName`) — все обращения пользователя, включая эти,
попадают в один тред с администрацией/модератором.
